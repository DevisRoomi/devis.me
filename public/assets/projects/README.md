# Folder Aset Proyek (Project Showcase)

Taruh gambar/tangkapan layar (screenshot) proyekmu di dalam folder ini!

### Format yang Disarankan:
- **Format file:** `.png`, `.jpg`, atau `.webp`
- **Rasio aspek ideal:** Landscape 16:10 atau 4:3 (contoh resolusi: `1200 x 750 px` atau `800 x 500 px`)
- **Contoh penamaan file:**
  - `basoku.png`
  - `duitin.png`
  - `setoran.png`
  - `projek4.png`

Nanti file gambar yang kamu taruh di sini bisa langsung dipanggil otomatis oleh website!
