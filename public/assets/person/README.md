# Folder Foto: 03 · THE PERSON (Abu Devis Jalaluddin Rumi)

Letakkan foto-foto pilihanmu untuk Section 03 (The Person) di dalam folder ini:
`public/assets/person/`

### Format & Rekomendasi Foto:
- Format file: `.jpg`, `.jpeg`, `.png`, atau `.webp`
- Rekomendasi nama file (bebas, bisa disesuaikan):
  - `devis_candid_1.jpg` (Foto candid/outdoor/reflektif)
  - `devis_candid_2.jpg` (Foto saat diskusi/interaksi/kampus IDN)
  - `devis_portrait.jpg` (Foto portrait berwibawa/editorial)
  - atau nama apa saja yang kamu sukai!

Sistem akan otomatis membaca foto dari folder ini saat kita menyusun Section 03!
